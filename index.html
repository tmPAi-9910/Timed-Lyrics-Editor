📖 How to Use

LRC Editor

  • Add Line: Click the "＋ Add Line" button to add a new lyric line
  • Edit Lyrics: Click on any lyric text to edit it
  • Set Timestamp: Click on the timestamp to edit it (format: mm:ss.xx)
  • Import LRC: Click "📥 Import LRC" to load an existing LRC file
  • Export LRC: Click "📤 Export LRC" to save your work

Preview

  • Load Audio: Select an audio file (MP3, WAV, etc.)
  • Play Controls: Use Play, Pause, and Stop buttons
  • Sync Lyrics: Lyrics will highlight based on timestamps

LRC Format

LRC files use the following format:

[mm:ss.xx] Lyric text
[00:12.34] Example line

Where:
  mm = minutes
  ss = seconds
  xx = centiseconds

Keyboard Shortcuts

  • Ctrl+N: Add new line
  • Ctrl+S: Export LRC
  • Ctrl+O: Import LRC
  • Space: Play/Pause (in Preview tab)
